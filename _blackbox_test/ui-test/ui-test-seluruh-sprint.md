# Lampiran E Test Case UI Testing - Seluruh Sprint

UI testing dilakukan untuk menguji aspek antarmuka aplikasi yang mencakup tiga cakupan utama, yaitu navigasi antar halaman, perilaku popup/modal/sheet, serta tampilan responsive pada berbagai ukuran layar. Pengujian ini bersifat lintas sprint dan mewakili fungsionalitas antarmuka dari sprint 1 hingga sprint 5.
